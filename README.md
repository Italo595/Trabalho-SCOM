# 🎮 Pokédex & Team Builder

Um site feito para consulta de informações relacionadas com a franquia Pokémon, com interatividade para montagem de equipas com análise de vantagens e fraquezas de tipo.

Projeto desenvolvido para o **Trabalho Individual I - SCOM (2026)**.

---

## 📂 Estrutura do Projeto

* `Trabalho1.html`: Estrutura HTML do projeto, contendo o catálogo de Pokémon, menu de categorias e os scripts JavaScript para gestão da equipa e análise de tipos.
* `Trabalho1.css`: Estilização completa da página, variáveis de temas, layouts responsivos e regras de acessibilidade.

---

## 🚀 Como Executar o Projeto

Como o projeto é desenvolvido exclusivamente com tecnologias nativas da web (HTML, CSS e JavaScript), não é necessário instalar nenhuma dependência ou gestor de pacotes.

### Opção 1: Abrir diretamente no Navegador (Recomendado)

1. Faça o clone deste repositório ou baixe o ficheiro ZIP:
   git clone [https://github.com/Italo595/Trabalho-SCOM.git](https://github.com/Italo595/Trabalho-SCOM.git)
